# P1. 엑사원 API 키 발급받기

LLM 도 Open-Meteo 처럼 HTTP 로 부르는 API 입니다. 다른 점은 **키가 있어야 답한다**는 것입니다. 오늘 실습은 LG 의 K-EXAONE 2.5 를 씁니다. 무료이고, 키는 계정마다 하나입니다.

## 키 발급 (브라우저)

1. https://docs.exaone.ai 에 들어가 **API Key 발급하기** 를 누르고 회원가입합니다. 가입 화면에 **이용 기록 분석(선택)** 이 나오면 동의합니다(동의하면 호출 한도가 올라갑니다). 이메일 인증까지 마칩니다.
2. 로그인한 뒤 **My Profile → API Key** 에서 키를 발급합니다.
3. **확인**: API Key 화면에 발급된 키와 만료일이 보이면 됩니다. 이 화면을 닫지 말고 P2 로 넘어갑니다.

## 지킬 것

- 키는 코드, 커밋, 카카오톡, 스크린샷 어디에도 넣지 않습니다. 넣는 곳은 P2 에서 만드는 `.env` 하나입니다.
- 입력한 내용이 모델 학습에 쓰일 수 있습니다. 이름, 학번 같은 개인정보는 프롬프트에 넣지 않습니다.
- 키는 발급 후 **30일** 뒤에 만료됩니다. 오늘 받은 키는 12/26 까지입니다. 팀 프로젝트를 엑사원으로 배포하는 조는 상호평가 전에 같은 메뉴에서 다시 발급받습니다.

커밋할 것은 없습니다.
